# 风雪

>世界上有两种代码。一种来自会写代码的人，一种来自趴在键盘上的猫
>
>猫喜欢趴在风雪的键盘上，于是提交了 commit，于是审阅了 PR
>
>也许会有一天，千万亿兆的神经网络越过常识的边界 —— 碳基的 硅基的 人类的 猫的
>
>也许会有一天，你会 merge 到来自未来的 PR，update 的 hash 不再遵循线性向前的时间
>
>如果到了那一天，请不要担心。那是猫和风雪让未来经过了昨天
